# Library source register (Phase 27)

Every rule, destination or fact in the disposal library cites one of these sources by its
**ID** (e.g. `S-RA9003-22`). Add new sources here first, with what they support and how sure
we are. Researched 2026-10-20; **re-check "verify" items before an entry using them is published.**

**Levels:** **P** = primary (the law, ordinance or agency text itself) · **S** = secondary
(news, NGO, consultancy summary of a primary source) · **I** = international reference (not
Philippine policy; use only for general safety practice, labelled as such).

## How to cite in an entry

`sources` column: one or more IDs separated by `;`, e.g. `S-RA9003-22;S-QC-T2C`. A **fact**
must have at least one P or S source. **Hazardous/medical items** need at least one P source,
or the item stays in draft with the safe fallback text above.
